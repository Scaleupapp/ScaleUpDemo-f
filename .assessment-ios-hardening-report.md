## Capstone Pairing Approach

Built `PlacementCapstonePairView.swift` which reuses `CapstonePairingCodePanel` (purely presentational — accepts `pairingCode: String`, `expiresAt: Date`, `laptopURL: String`). Did NOT reuse `CapstonePairView` because it requires a `CapstoneLibraryEntry` bundle and calls `CapstoneService.shared.getStatus(sessionId:)` — a different domain's endpoint with a different session ID type.

The pairing view polls `PlacementsAssessmentsApi.shared.syncSession(assessmentSessionId)` every 20 s for up to 5 minutes (15 iterations). On `status == "graded"`, switches to a "done" state with a Done button. On dismiss, triggers a final sync + list reload + optional grade poll.

## Mic Gate Approach

`PlacementInterviewTakeView.swift` owns a `MicState` enum (`checking / granted / denied`). On `.task`, calls `AVCaptureDevice.authorizationStatus(for: .audio)` — if `.authorized` proceeds directly; if `.notDetermined` awaits `AVCaptureDevice.requestAccess(for: .audio)`; otherwise shows the mic-denied screen. `vm.attachSession` is only called after mic is confirmed granted. Denial shows a blocking screen with "Open Settings" → `UIApplication.openSettingsURLString` and a "Close" button — never reaches `attachSession`.

## Concerns

- **ISO8601 `expiresAt` parsing**: `PlacementCapstonePairView` uses plain `ISO8601DateFormatter()` which handles `Z`-suffixed strings but NOT fractional seconds (e.g. `2026-06-25T10:00:00.000Z`). If backend sends fractional seconds, the date parse fails silently and the view falls through to `missingCodeView`. Fix: use `ISO8601DateFormatter` with `.withFractionalSeconds` option as a fallback (same pattern as `V2APIClient.decoder`).
- **Capstone laptop URL**: Falls back to a hardcoded `scaleup-web-seven.vercel.app/capstone`. Should be promoted to a proper `Info.plist` key `CAPSTONE_WEB_URL` set per environment.
