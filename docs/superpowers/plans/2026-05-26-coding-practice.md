# ScaleUp Coding Practice — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Spec:** [`docs/superpowers/specs/2026-05-26-coding-practice-design.md`](../specs/2026-05-26-coding-practice-design.md)

**Goal:** Ship a mobile-first coding practice surface across ScaleUp (Drills → Capstones → TPO/expansion) that trains and grades the AI-augmented-coding meta-skills companies actually hire for in 2026.

**Architecture:** Backend extends `scaleup-backend` with a new `coding/` module (routes, services, workers, models); content is system-generated by a cross-validated LLM pipeline (Claude Opus + Gemini 2.5 Pro); mobile clients (iOS + Android) consume via existing OpenAPI contract; web IDE (Next.js + Monaco) is added in Phase B for Capstones; sandbox is managed (e2b.dev) at launch.

**Tech Stack:** Node.js + Express + Mongoose + BullMQ + Redis + S3 (backend); SwiftUI 6 (iOS); React Native 0.84 + Redux Toolkit + TypeScript (Android); Next.js + Monaco (web, Phase B); Claude Sonnet 4.6 / Opus 4.7 / Haiku 4.5 + Gemini 2.5 Pro (LLM); e2b.dev (sandbox, Phase B).

**Plan structure:**
- **Phase A** — Drills launch (full TDD task-level detail, executable now)
- **Phase B** — Capstones launch (outline; gets its own detailed plan once Phase A stable)
- **Phase C** — TPO + expansion (milestone list; detailed plans per sub-feature later)

**Repos affected:**

- `~/My Products/ScaleUpDemo-f` — iOS app

## Conventions used throughout this plan

- **File paths** are repo-relative. Repo root is shown in the `Files:` block.
- **Test framework** — backend uses existing `scripts/run-tests.js` pattern (extends node:test or jest, whichever the repo already uses); iOS uses XCTest; Android uses Jest.
- **Commit style** — `<type>(<scope>): <subject>` per existing repo convention. Types: `feat`, `fix`, `test`, `chore`, `docs`, `refactor`.
- **OpenAPI first** — every backend route is added to `openapi.yaml` BEFORE implementation, then mobile clients regenerate types.
- **No mocks for LLM calls in integration tests** — use cheap models (Haiku) with deterministic seed prompts; mock only in unit tests.
- **Each task ends with a commit** — frequent commits, scoped to that task.

- [ ] **Step 3: Implement validator**

```javascript
const Joi = require('joi');

const promptSubmission = Joi.object({
  prompt_text: Joi.string().min(10).max(8000).required(),
});

const verifySubmission = Joi.object({
  bug_locations: Joi.array().items(Joi.object({
    file: Joi.string().required(),
    line: Joi.number().integer().min(0).required(),
    explanation: Joi.string().min(5).max(2000).required(),
  })).min(1).required(),
});

const decomposeSubmission = Joi.object({
  decomposition_steps: Joi.array().items(Joi.object({
    step: Joi.string().required(),
    rationale: Joi.string().required(),
  })).min(2).max(10).required(),
});

const refactorSubmission = Joi.object({
  refactored_code: Joi.object({
    files: Joi.array().items(Joi.object({
      path: Joi.string().required(),
      content: Joi.string().required(),
    })).min(1).required(),
  }).required(),
});

const subtypeSchemas = {
  prompt: promptSubmission,
  verify: verifySubmission,
  decompose: decomposeSubmission,
  refactor: refactorSubmission,
};

function validateDrillSubmission(payload) {
  const outer = Joi.object({
    drill_subtype: Joi.string().valid('prompt', 'verify', 'decompose', 'refactor').required(),
    submission: Joi.object().required(),
  }).validate(payload);
  if (outer.error) return outer;
  const inner = subtypeSchemas[payload.drill_subtype].validate(payload.submission);
  return inner;
}

function validateDrillStart(payload) {
  return Joi.object({
    role_track: Joi.string().valid('swe', 'ds', 'ai_eng').required(),
    difficulty: Joi.string().valid('easy', 'medium', 'hard').required(),
    drill_subtype: Joi.string().valid('prompt', 'verify', 'decompose', 'refactor').required(),
    is_calibration: Joi.boolean().default(false),
  }).validate(payload);
}

module.exports = { validateDrillSubmission, validateDrillStart };
```

```javascript
  return entry;

async function llmCall({ taskId, system, messages, prompt, tools: extraTools }) {
  const { provider, model, tools: defaultTools = [] } = getModelForTask(taskId);
  const tools = [...defaultTools, ...(extraTools || [])];

  // TODO: emit metrics to existing analytics layer
  return { ...result, _meta: { taskId, provider, model, duration_ms } };
}
```

```javascript
const { ArtifactBundle, DrillAttempt } = require('../../models');
const { llmCall } = require('../llmRouter');
const { flattenRubric } = require('./rubric');

const SYSTEM = `You grade Prompt Drills. The learner is given a brief and must write a prompt that gets an LLM to solve the task correctly.

Score 0-10 on each rubric dimension:
- specificity: is the prompt specific enough to constrain the model
- constraints: does it declare invariants (format, length, edge cases)
- edge_cases: does it pre-empt failure modes
- output_fidelity: would a typical LLM produce the expected output

Return strict JSON: { overall_score (0-100), rubric: { specificity, constraints, edge_cases, output_fidelity }, what_to_try_next: string (<=200 chars) }`;

async function grade({ drillAttemptId }) {
  const attempt = await DrillAttempt.findById(drillAttemptId).lean();
  if (!attempt) throw new Error(`DrillAttempt ${drillAttemptId} not found`);
  const bundle = await ArtifactBundle.findById(attempt.bundle_id).lean();

  const res = await llmCall({
    taskId: 'drill_grade_prompt',
    system: SYSTEM,
    messages: [{ role: 'user', content: userMsg }],
  });

  const text = res.content[0].text;
  const parsed = JSON.parse(text);

  await DrillAttempt.findByIdAndUpdate(drillAttemptId, {
    status: 'graded',
    grade: {
      overall_score: parsed.overall_score,
      rubric_breakdown: flattenRubric(parsed.rubric),
      what_to_try_next: parsed.what_to_try_next,
      integrity_confidence: 'high',
      graded_at: new Date(),
      grader_model: res._meta.model,
    },
  });

}
```

```javascript
const { ArtifactBundle, DrillAttempt } = require('../../models');
const { llmCall } = require('../llmRouter');
const { flattenRubric } = require('./rubric');

const SYSTEM = `You grade Verify Drills. The learner is shown code with planted bugs and must mark each bug + explain.

Compute:
- detection_accuracy: (true_positives / total_seeded) * 10
- root_cause_clarity: 0-10 based on explanation quality (LLM judgment)
- false_positive_rate: penalty if learner marks correct code as buggy

Return strict JSON: { overall_score (0-100), rubric: { detection_accuracy, root_cause_clarity, false_positive_rate }, what_to_try_next: string }`;

async function grade({ drillAttemptId }) {
  const attempt = await DrillAttempt.findById(drillAttemptId).lean();
  const bundle = await ArtifactBundle.findById(attempt.bundle_id).lean();

  const seeded = bundle.seeded_mistakes;
  const reported = attempt.submission.bug_locations;

  const matched = reported.filter(r =>
    seeded.some(s => s.location.includes(r.file) && Math.abs(parseInt(s.location.split(':')[1] || '0') - r.line) <= 2)
  );
  const detection_accuracy = (matched.length / seeded.length) * 10;
  const false_positives = reported.length - matched.length;

  const userMsg = `SEEDED:\n${JSON.stringify(seeded)}\n\nLEARNER REPORTED:\n${JSON.stringify(reported)}\n\nMATCHED: ${matched.length}/${seeded.length}\nFALSE POSITIVES: ${false_positives}\n\nScore root_cause_clarity (0-10) based on explanation quality.`;

  const res = await llmCall({
    taskId: 'drill_grade_verify',
    system: SYSTEM,
    messages: [{ role: 'user', content: userMsg }],
  });

  const parsed = JSON.parse(res.content[0].text);
  parsed.rubric.detection_accuracy = detection_accuracy;
  parsed.rubric.false_positive_rate = Math.max(0, 10 - false_positives * 2);
  const overall = Math.round((detection_accuracy * 0.5 + parsed.rubric.root_cause_clarity * 0.3 + parsed.rubric.false_positive_rate * 0.2) * 10);

  await DrillAttempt.findByIdAndUpdate(drillAttemptId, {
    status: 'graded',
    grade: {
      overall_score: overall,
      rubric_breakdown: flattenRubric(parsed.rubric),
      what_to_try_next: parsed.what_to_try_next,
      integrity_confidence: 'high',
      graded_at: new Date(),
      grader_model: res._meta.model,
    },
  });

  return { overall_score: overall, ...parsed };
}

module.exports = { grade };
```

```javascript
const { execFileSync, execFile } = require('child_process');
const fs = require('fs');
const path = require('path');
const os = require('os');

async function runInTempDir({ files, command, timeout_ms = 15000 }) {
  const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'scaleup-sbx-'));
  try {
    for (const f of files) {
      const target = path.join(dir, f.path);
      fs.mkdirSync(path.dirname(target), { recursive: true });
      fs.writeFileSync(target, f.content);
    }
    return await new Promise((resolve) => {
      execFile('sh', ['-c', command], { cwd: dir, timeout: timeout_ms }, (err, stdout, stderr) => {
        resolve({ exit_code: err ? err.code || 1 : 0, stdout, stderr, timed_out: err?.signal === 'SIGTERM' });
      });
    });
  } finally {
    fs.rmSync(dir, { recursive: true, force: true });
  }
}
```

```javascript
const { ArtifactBundle } = require('../models');
const { llmCall } = require('./llmRouter');
const { bundleSchema } = require('./bundleSchema');
const { computeContentHash } = require('./contentHash');

async function nearestSeeds({ role_track, drill_subtype, difficulty }, k = 3) {
  return ArtifactBundle.find({
    role_track, drill_subtype, status: 'active',
    'generated_by.human_reviewed': true,
  }).sort({ difficulty: difficulty === 'easy' ? 1 : -1 }).limit(k).lean();
}

async function generate({ role_track, drill_subtype, difficulty, language, topic_hint }) {
  const seeds = await nearestSeeds({ role_track, drill_subtype, difficulty });
  const system = `You generate ArtifactBundles for ScaleUp coding practice. Output strict JSON matching the schema. Use the seed examples as quality reference, but produce a NEW problem.`;
  const prompt = `SEEDS:\n${JSON.stringify(seeds, null, 2)}\n\nTARGET:\nrole_track=${role_track}, drill_subtype=${drill_subtype}, difficulty=${difficulty}, language=${language}\nTOPIC HINT: ${topic_hint || 'none'}\n\nGenerate a complete ArtifactBundle.`;

  const res = await llmCall({
    taskId: 'content_generator_draft',
    system,
    messages: [{ role: 'user', content: prompt }],
    tools: [{ type: 'code_execution_20250522', name: 'code_execution' }],
  });

  const json = extractJson(res.content);
  json.content_hash = computeContentHash(json);
  const { error, value } = bundleSchema.validate(json);
  if (error) throw new Error(`Generator output invalid: ${error.message}`);
  value.generated_by = { generator_model: res._meta.model, validator_model: null, validated_at: null, human_reviewed: false };
  value.status = 'draft';
  const saved = await ArtifactBundle.create(value);
  return saved;
}

module.exports = { generate, nearestSeeds };
```

```javascript
async function getToday(req, res) {
  const userId = req.user._id;
  const user = await User.findById(userId).lean();
  const role_track = mapObjectiveToRoleTrack(user.primary_objective); // helper

  let diffState = await DifficultyState.findOne({ user_id: userId, role_track });
  if (!diffState) {
    diffState = await DifficultyState.create({ user_id: userId, role_track, current_difficulty: 'easy', recommendation_history: [] });
  }

  const mastery = await MetaSkillMastery.findOne({ user_id: userId, role_track });
  const weakestAxis = pickWeakestAxis(mastery);
  const drill_subtype = axisToSubtype(weakestAxis); // prompting→prompt, etc.

  const bundle = await ArtifactBundle.findOne({
    type: 'drill', role_track, difficulty: diffState.current_difficulty,
    drill_subtype, status: 'active',
  }).sort({ createdAt: -1 });

  if (!bundle) return res.status(404).json({ error: 'no_drill_available' });
  return res.json({ bundle_id: bundle._id, brief: bundle.brief, time_budget_minutes: bundle.time_budget_minutes, drill_subtype, difficulty: bundle.difficulty, role_track });
```
